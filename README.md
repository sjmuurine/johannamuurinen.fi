# johannamuurinen.fi

Johanna Muurisen eduskuntavaalisivusto (Vihreät, Uusimaa, 2027).

## Tiedostot

- `index.html` – koko sivusto: etusivu, Politiikka, Kantani, Tutkimus ja Hevoset. Osiot ovat samassa tiedostossa, ja niihin pääsee osoitteilla kuten `johannamuurinen.fi/#politiikka`.
- `kuvat/` – sivuston kuvat. `jakokuva.jpg` näkyy, kun sivun linkki jaetaan somessa.
- `fonts/` – fontit (Barlow Semi Condensed, IBM Plex Sans ja IBM Plex Mono). Ne ladataan omalta palvelimelta, joten kävijöiden tietoja ei välity Googlelle.
- `CNAME` – kertoo GitHubille, että sivu näkyy osoitteessa johannamuurinen.fi. Älä poista.
- `favicon.svg` – selaimen välilehden kuvake.
- `.nojekyll` – estää GitHubia käsittelemästä tiedostoja. Älä poista.

## Tekstin muuttaminen

Avaa `index.html` GitHubissa, paina kynäkuvaketta ja etsi muutettava teksti (Ctrl/Cmd + F). Tallenna painamalla *Commit changes*. Sivu päivittyy minuutin parin kuluttua.
